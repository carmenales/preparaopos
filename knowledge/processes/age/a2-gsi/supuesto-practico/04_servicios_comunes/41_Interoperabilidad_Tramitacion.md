## 2. SERVICIOS DETALLADOS DE INTEROPERABILIDAD

Este catálogo amplía la información y justifica el uso de sistemas menos obvios que pueden aparecer en los supuestos (RRHH, Georreferenciación, etc.).

### 2.1. Servicios de Registro, Gestión y Archivo

| Servicio | Función Detallada (Criterio de Uso) |
| :--- | :--- |
| **SIR** (Interconexión) | Permite el intercambio de asientos registrales entre AAPP (CCAA, EELL, AGE). |
| **GEISER** | Gestión y digitalización de documentos y su intercambio mediante SIR. |
| **ORVE** | Oficina de Registro Virtual. Para la **digitalización de documentos presentados presencialmente** por ciudadanos (OAMR). |
| **ACCEDA** | Interfaz de sede electrónica que permite la **gestión y tramitación** de procedimientos (Solución "todo en uno" para pequeños organismos). |
| **SIA** | Inventario centralizado de **procedimientos administrativos** y servicios (Necesario para codificar trámites). |
| **CTT** | **Consulta obligatoria** de soluciones tecnológicas reutilizables entre las AAPP. |

### 2.2. Servicios Transversales (RRHH, Finanzas y Atención)

| Servicio | Función Detallada (Criterio de Uso) |
| :--- | :--- |
| **NEDAES** | Sistema de gestión de la **nómina** de los empleados públicos (a citar en supuestos de RRHH). |
| **FUNCIONA** | Portal del empleado público (Consulta de nómina, permisos, etc.). |
| **PLATA** | Plataforma de **Traducción Automática** (Idiomas cooficiales y UE). |
| **EGEO** | Servicios de **georreferenciación** de datos (Representación en mapas y cuadros de mando). |
| **060** | Teléfono único de atención al ciudadano (Infraestructura de **Atención Multicanal**). |
| **FACE** | Plataforma para la presentación de **facturas electrónicas** por parte de proveedores. |
